## Context

SWLOR builds its own combat log (`Combat.BuildCombatLogMessage`), and Wave 2 will convert that log to
Shadowrun pool vocabulary. Alongside it, the NWN engine emits its own native combat feedback in D&D
terms — saving throws, touch attacks, spell resistance — which will read as obviously wrong next to a
Shadowrun-flavoured log.

`FeedbackMessageConfiguration.ConfigureFeedbackMessages` already suppresses two of these through NWNX
and is the single place this is controlled:

```
FeedbackPlugin.SetFeedbackMessageHidden(FeedbackMessageTypes.UseItemCantUse, true);
FeedbackPlugin.SetFeedbackMessageHidden(FeedbackMessageTypes.CombatRunningOutOfAmmo, true);
FeedbackPlugin.SetFeedbackMessageHidden(FeedbackMessageTypes.RestBeginningRest, true);
FeedbackPlugin.SetFeedbackMessageHidden(FeedbackMessageTypes.RestFinishedRest, true);
FeedbackPlugin.SetFeedbackMessageHidden(FeedbackMessageTypes.RestCancelRest, true);

FeedbackPlugin.SetCombatLogMessageHidden(CombatLogMessageType.Initiative, true);
FeedbackPlugin.SetCombatLogMessageHidden(CombatLogMessageType.ComplexAttack, true);
```

Available values are in `SWLOR.NWN.API/NWNX/Enum/CombatLogMessageType.cs` and
`SWLOR.NWN.API/NWNX/Enum/FeedbackMessageTypes.cs`. Read both before choosing.

## Requirements

1. Extend the existing suppression list to cover native combat-log message types whose vocabulary is
   D&D-specific and therefore wrong for this setting. Strong candidates, each of which you must
   confirm against the enum before using: `SavingThrow`, `TouchAttack`, `SpellResistance`,
   `Counterspell`, `DispelMagic`, `Polymorph`.
2. **Be conservative and justify every addition with a short comment** explaining what the player
   stops seeing and why that is correct. A suppression that hides useful feedback is worse than one
   that leaks a stale term.
3. **Do not suppress damage or death feedback** — `SimpleDamage`, `ComplexDamage`, `ComplexDeath`,
   `SimpleAdjective`. SWLOR relies on native damage display, and hiding it would leave players unable
   to see that they are being hurt. If you believe one of these should change, say so in your final
   message instead of doing it.
4. **Do not suppress `CombatLogMessageType.Feedback` (11).** Its own comment in the enum warns it
   hides *all* feedback messages; individual messages must be hidden via
   `SetFeedbackMessageHidden` instead.
5. **Do not suppress `CastSpell`.** SWLOR routes its abilities through `spells.2da`, so hiding it
   risks hiding ability feedback. Flag it in your final message if you think it warrants review.
6. Keep the existing five feedback and two combat-log suppressions exactly as they are.
7. Match the file's existing style: same call shape, same grouping, same indentation.
