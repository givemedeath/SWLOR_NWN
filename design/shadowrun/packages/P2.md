## Context

The character sheet is the densest concentration of SWLOR combat vocabulary a player sees, and it
funnels every displayed stat through **one helper**, which is what makes this package tractable:

- `AddStat(string name, string value, string tooltip)` — declared around line 888, with roughly 38
  call sites immediately following it.
- `FormatPercent(int value)` — around line 1081, the sole formatter for percentage stats.
- The Attributes tab bindings around lines 842–848 assign `Attack`, `ForceAttack`, `PhysicalDefense`,
  `ForceDefense`, `Accuracy`, and `Evasion` from `Stat.*` calls.

Line numbers are from the time of writing — **locate by symbol, not by line**, in case the file moved.

`SWLOR.Game.Server/Service/ShadowrunDisplay.cs` (delivered in Wave 0) is the single source of truth
for every translation. Its public surface:

```csharp
ShadowrunDisplay.GetAttackPool(int accuracy)                       // Accuracy  -> dice pool
ShadowrunDisplay.GetDefensePool(int evasion)                       // Evasion   -> dice pool
ShadowrunDisplay.FormatOpposedTest(int accuracy, int evasion)      // "(Pool 12 vs 9)"
ShadowrunDisplay.GetDamageValue(int weaponDamage)                  // DMG       -> DV
ShadowrunDisplay.GetPhysicalConditionBoxes(int currentHP, int maxHP)
ShadowrunDisplay.GetStunConditionBoxes(int currentStamina, int maxStamina)
ShadowrunDisplay.GetEdge(int forcePoints)                          // FP        -> Edge
ShadowrunDisplay.GetSkillRating(int rank)                          // 1-50      -> 1-7
ShadowrunDisplay.GetAttributeRating(int score)
ShadowrunDisplay.ConditionMonitorBoxes                             // const
```

## Requirements

1. Relabel the `AddStat` call sites to Shadowrun vocabulary. **Rewrite the tooltips too** — they carry
   as much explanatory load as the labels, and a Shadowrun label over a SWLOR tooltip is worse than
   leaving both alone.
2. Add a `FormatPool` formatter alongside `FormatPercent`, routing through `ShadowrunDisplay`. Keep
   `FormatPercent` — percentage stats that have no pool equivalent (critical damage, movement speed,
   enmity, XP rate) should stay percentages. **Do not force everything into pool vocabulary.**
3. Update the Attributes tab bindings so Accuracy and Evasion display as pools, and attribute scores
   display as Shadowrun attribute ratings.
4. Where a stat has no meaningful Shadowrun equivalent, leave its vocabulary alone and note it in your
   final message. An honest SWLOR term beats an invented Shadowrun one.
5. Preserve all existing behaviour: the same stats appear, in the same order, on the same tabs. This
   is a presentation change only — no stat may be added, removed, reordered, or recomputed.
6. Do not call `ShadowrunDisplay` more than once per displayed value. Convert, then format.

### Vocabulary guide

| SWLOR | Shadowrun |
|---|---|
| Accuracy | Attack Pool |
| Evasion | Defense Pool |
| Attack / Force Attack | keep as-is for now — Wave 2 owns the damage side |
| Physical DEF / Force DEF | Armor / Astral Armor |
| DMG | DV (Damage Value) |
| HP | Physical (condition monitor) |
| Stamina / STM | Stun (condition monitor) |
| FP | Edge |
| skill rank | skill rating |

Anything not in this table is a judgement call — make it, and say what you chose and why.
